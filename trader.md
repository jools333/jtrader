## Задача
Создай модуль торгового агента на PHP, который анализирует свечные данные и генерирует сигналы на вход и выход из позиции по следующим правилам. 

---

## Входные данные

Агент принимает массив свечей в формате:
```php
$candles = [
    ['time' => 1700000000, 'open' => 100.0, 'high' => 105.0, 'low' => 98.0, 'close' => 103.0, 'volume' => 1500],
    // ... минимум 50 свечей, отсортированы от старых к новым
];

$level  = 100.0;   // ключевой горизонтальный уровень (поддержка или сопротивление)
$atr    = 8.5;     // значение ATR(14) для текущего инструмента
```

---

## Индикаторы (реализуй все сам)

### ATR(14) — Average True Range
```
TrueRange[i] = max(High[i]-Low[i], abs(High[i]-Close[i-1]), abs(Low[i]-Close[i-1]))
ATR = SMA(TrueRange, 14)
```

### EMA(period) — Exponential Moving Average
```
k = 2 / (period + 1)
EMA[0] = Close[0]
EMA[i] = Close[i] * k + EMA[i-1] * (1 - k)
```
Используй EMA(8) — быстрая и EMA(21) — медленная.

### MACD(12, 26, 9)
```
MACD_line    = EMA(12) - EMA(26)
Signal_line  = EMA(9) от MACD_line
Histogram    = MACD_line - Signal_line
```

### Свечи сжатия (compression)
Свеча считается свечой сжатия, если выполняются ОБА условия:
- `abs(close - open) < ATR * 0.3`  (маленькое тело)
- `(high - low) < ATR * 0.6`       (маленький полный диапазон)

### Импульсная свеча
- `abs(close - open) > ATR * 0.5`  (большое тело)
- `close > open` — бычий импульс
- `close < open` — медвежий импульс

---

## 4 правила входа

### Правило 1: Отбой от уровня (Bounce)
**Условия для шорта (цена у сопротивления):**
1. Последние 3–5 свечей находятся в зоне `level ± ATR * 0.15`
2. Минимум 2 из 3 последних свечей — свечи сжатия
3. Последняя закрытая свеча — медвежий импульс (`close < open`, тело > `ATR * 0.5`)
4. EMA(8) находится ниже уровня или разворачивается вниз: `EMA8[i] < EMA8[i-1]`
5. MACD Histogram снижается: `histogram[i] < histogram[i-1]`
6. ATR пройден не более чем на 20% от уровня вниз

**Условия для лонга (цена у поддержки):** зеркально.

**Сигнал:** `['type' => 'BOUNCE', 'direction' => 'SHORT'|'LONG']`

---

### Правило 2: Пробой + Ретест (Breakout Retest)
**Условия для лонга:**
1. Была большая бычья свеча с закрытием выше уровня: тело > `ATR * 0.7`, `close > level`
2. После пробоя цена откатила обратно к уровню: текущая цена в зоне `level ± ATR * 0.2`
3. EMA(8) > level (EMA удержалась выше пробитого уровня)
4. EMA(8) > EMA(21) (бычий контекст)
5. MACD_line > 0 (выше нулевой линии)
6. Появился сигнал: минимум 1 свеча сжатия + последняя свеча бычий импульс

**Условия для шорта:** зеркально (пробой вниз, ретест снизу).

**Сигнал:** `['type' => 'RETEST', 'direction' => 'SHORT'|'LONG']`

---

### Правило 3: Ложный пробой (False Breakout)
**Условия для шорта:**
1. Предпоследняя свеча: `high > level + ATR * 0.1` (хвост пробил уровень)
   НО `close < level` (тело закрылось ниже уровня)
2. Размер хвоста выше уровня: `high - level > ATR * 0.15`
3. Последняя свеча: медвежий импульс, `close < open`, тело > `ATR * 0.4`
4. EMA(8) < level или EMA(8) разворачивается вниз
5. MACD Histogram < 0 или снижается

**Условия для лонга:** зеркально (хвост ниже уровня, тело закрылось выше).

**Сигнал:** `['type' => 'FALSE_BREAKOUT', 'direction' => 'SHORT'|'LONG']`

---

### Правило 4: Откат в тренде + ATR-зона (Trend Pullback)
**Условия для лонга:**
1. Тренд подтверждён: EMA(8) > EMA(21) на протяжении последних 5 свечей
2. Цена откатила к уровню поддержки: текущая цена в зоне `level ± ATR * 0.15`
3. ATR использован на 0–20%: `(currentPrice - level) / ATR < 0.20`
4. Минимум 1 свеча сжатия у уровня
5. Последняя свеча — бычий импульс
6. EMA(21) ≈ level (EMA совпадает с уровнем): `abs(EMA21[i] - level) < ATR * 0.2`
   → если совпадает — двойное подтверждение, добавить флаг `'confluence' => true`
7. MACD: нет медвежьей дивергенции (цена не обновила минимум при растущем MACD)

**Условия для шорта:** зеркально (EMA(8) < EMA(21), откат к сопротивлению).

**Сигнал:** `['type' => 'TREND_PULLBACK', 'direction' => 'SHORT'|'LONG', 'confluence' => bool]`

---

## 4 правила выхода

Агент принимает текущую открытую позицию:
```php
$position = [
    'direction'    => 'LONG',   // LONG | SHORT
    'entry_price'  => 91.0,
    'stop_price'   => 88.5,
    'target1'      => 101.0,    // цель 1 (R:P = 1:2 минимум)
    'target2'      => 111.0,    // цель 2 (следующий уровень / ATR)
    'size'         => 1.0,      // 100% позиции
    'breakeven_set'=> false,    // был ли перенесён стоп в безубыток
];
```

---

### Правило выхода 1: Частичная фиксация на Цели 1
**Условие:**
- Текущая цена достигла `target1`

**Действие:**
- Закрыть 50% позиции
- Установить `breakeven_set = true` (стоп переносится на `entry_price`)

**Сигнал:** `['exit_type' => 'TARGET1', 'close_percent' => 50, 'move_stop_to' => entry_price]`

---

### Правило выхода 2: Полный выход на Цели 2
**Условие:**
- Текущая цена достигла `target2`

**Действие:**
- Закрыть оставшиеся 50% позиции

**Сигнал:** `['exit_type' => 'TARGET2', 'close_percent' => 100]`

---

### Правило выхода 3: Досрочный выход по сигналу разворота
Выйти **раньше цели**, если у следующего уровня появился сигнал разворота против позиции.

**Условия (для лонга — сигнал разворота вниз):**
1. Минимум 2 свечи сжатия подряд
2. Последняя свеча — медвежий импульс (тело > `ATR * 0.5`)
3. Выполняется ХОТЯ БЫ ОДНО из:
   - MACD дивергенция: цена обновила максимум, MACD_line — нет
   - Большой объём + маленькое тело (усилие без результата): `volume[i] > avg_volume * 1.5` И тело свечи < `ATR * 0.2`
   - EMA(8) развернулась против позиции: для лонга `EMA8[i] < EMA8[i-1] < EMA8[i-2]`

**Действие:** Закрыть 100% позиции.

**Сигнал:** `['exit_type' => 'EARLY_REVERSAL', 'close_percent' => 100, 'reason' => 'divergence'|'absorption'|'ema_turn']`

---

### Правило выхода 4: Стоп-лосс
**Условие:**
- Если `breakeven_set = false`: цена достигла `stop_price`
- Если `breakeven_set = true`: цена вернулась к `entry_price`

**Действие:** Закрыть 100% позиции.

**Сигнал:** `['exit_type' => 'STOP_LOSS', 'close_percent' => 100]`

---

## Формат возвращаемого значения

```php
return [
    'entry_signal' => [               // null если сигнала нет
        'type'      => 'BOUNCE',      // BOUNCE | RETEST | FALSE_BREAKOUT | TREND_PULLBACK
        'direction' => 'LONG',        // LONG | SHORT
        'confluence'=> false,         // только для TREND_PULLBACK
        'stop'      => 88.5,          // уровень стоп-лосса
        'target1'   => 101.0,
        'target2'   => 111.0,
        'rr_ratio'  => 4.0,           // соотношение reward/risk до target2
    ],
    'exit_signal' => [                // null если сигнала нет
        'exit_type'     => 'TARGET1',
        'close_percent' => 50,
        'move_stop_to'  => 91.0,      // null если не применимо
        'reason'        => null,      // для EARLY_REVERSAL
    ],
    'indicators' => [
        'ema8'       => 90.3,
        'ema21'      => 89.8,
        'macd_line'  => 0.45,
        'macd_signal'=> 0.32,
        'macd_hist'  => 0.13,
        'atr'        => 8.5,
    ],
];
```

---

## Ограничения и защиты

- Если `rr_ratio < 2.0` — сигнал входа НЕ генерировать
- Если за последние 5 свечей уже был сигнал входа того же типа — не дублировать
- Не генерировать сигнал если: ATR пройден более 60%, или ширина последних 5 свечей < `ATR * 0.3` (узкий флет)
- Код покрыть PHPDoc-комментариями на ключевых методах

Формат данных можешь под текущую реализацию подстроить, главное чтобы выполнялись алгоритмы входа и выхода. 
Вход в позицию с TP/SL и закрытие позиции агент будет делать сам (есть API ключ). Реализация также должны быть абстрактной с возможностью переключится на другую биржу.

Все позиции в которые заходит агент должны логироваться в базе данных, с указанием параметров из-за которых был вход в позцию и выход из нее (в идеале прикрепить скрин графика с уровнями, ema и пр. к позиции)
